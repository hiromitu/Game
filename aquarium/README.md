# Aquarium

Three.js で描くブラウザ用の 3D アクアリウム。ビルド不要（Three.js は CDN から importmap で読み込み）。

## 起動

Python 3 が必要。

```bash
git clone https://github.com/hiromitu/Game.git
cd Game/aquarium
python serve.py
```

ブラウザで http://localhost:8765/ を開く。ES Modules を使うので `index.html` を直接開いても動かない。
Windows では `python -m http.server` だと `.js` が text/plain で返り読み込めないことがあるため、`serve.py` を使う。

## 操作

- ドラッグ：視点回転（水槽の裏側へは回り込めない） / ホイール：ズーム / 右ドラッグ：平行移動
- パネル：ポンプの強さ・ON/OFF、昼/夜、自動回転

## 構成

| ファイル | 内容 |
| --- | --- |
| `src/config.js` | 水槽寸法、共有ユニフォーム、底床の高さ関数、乱数・ノイズ |
| `src/shaders.js` | ポンプの水流場（JS と GLSL で同じ式）、水中の色吸収・コースティクス、標準マテリアルへの差し込み |
| `src/terrain.js` | 砂の斜面、砂利、岩組み、背面の岩壁、流木、魚が避ける障害物 |
| `src/plants.js` | バリスネリア・ヘアーグラス・有茎草・アマゾンソード・ミクロソリウム。水流で頂点シェーダーが曲げる |
| `src/pump.js` | 外掛けフィルター、吸水パイプ、落水、落水点の泡立ち、泡と飛沫のパーティクル |
| `src/tank.js` | ガラス、枠、水面、照明器具、キャビネット |
| `src/fishModels.js` | 魚の形状（体・ひれ・目）と、泳ぎの体のくねりを入れるシェーダー |
| `src/fish.js` | 種ごとの行動 |

## 魚の行動

- **ネオンテトラ**：ボイドで群泳し、群れの目的地が時々移る。エンゼルフィッシュが近づくと散る
- **エンゼルフィッシュ**：目的地までゆっくり移動しては長く静止する。時々ネオンを短く追い回す
- **グッピー**：水面近くで方向転換・急発進・停止を繰り返し、水面をついばむ。オスはメスの横について体をくねらせる
- **コリドラス**：底を頭を下げて探りながら移動し、休む。まれに水面まで泳ぎ上がって息継ぎし、底へ戻る
