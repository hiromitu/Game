# Punch Runner

Three.js で作った 3D アクションゲーム。ステージは 1m のブロックを詰めた立方体で、中に丘・山・谷・川・湖が広がっている。
キャラの後ろ（右肩越し）からの視点で、マウスで向きを変えながら進み、光の柱が立つゴールのゲートに入るとステージクリア。
**水以外のブロックはすべてパンチで壊せる**ので、壁は登っても掘り抜いてもよく、足元を掘って地下へ進むこともできる。ビルド不要（Three.js は CDN から importmap で読み込み）。

## 起動

Python 3 が必要。

```bash
cd Game/punch-runner
python serve.py
```

ブラウザで http://localhost:8767/ を開く。ES Modules を使うので `index.html` を直接開いても動かない。
Windows では `python -m http.server` だと `.js` が text/plain で返り読み込めないことがあるため、`serve.py` を使う。

## 操作

スタートすると画面にマウスがロックされ、マウスの動きでキャラの向きが変わる（Esc でロック解除＝ポーズ）。

| 操作 | 入力 |
| --- | --- |
| 向き | マウスを動かす（左右・上下）。画面中央の照準が狙い。狙ったブロックは黒い枠で囲まれる |
| パンチ | 左クリック。照準の先のブロックを殴る。上を向けば頭上、下を向けば足元を殴れる。走りながら正面を殴るとダッシュパンチ（2 ダメージ） |
| 急降下パンチ | 空中で真下を向いて左クリック（2 ダメージ） |
| ジャンプ | 右クリック（長押しで高く、早く離すと低く）。水中では長押しで浮上 |
| 移動 | WASD / 矢印キー（向いている方向が前） |
| 走る | Shift を押しながら移動 |
| よじ登る | ブロックの側面に向かって進み続ける。1 段の段差はすぐ乗り上がる。登りながらでもパンチできる |
| 壁から離れる | 登っている最中に右クリック（壁ジャンプ）/ S |
| カメラの距離 | ホイール |
| その他 | Esc・P：ポーズ（マウス感度の調整もここ）/ R：ステージやり直し / M：音 / H：操作説明の表示切替 |

Space でジャンプ、J でパンチもできる。

## ブロック

| ブロック | パンチ回数 | 備考 |
| --- | --- | --- |
| 草・土・葉・砂・雪・木箱・板 | 1 | 砂と木箱は下が空くと落ちてくる |
| 木・レンガ・石畳 | 2 | |
| 石 | 3 | |
| 水 | 壊せない | 隣のブロックを壊すと、空いたところへ流れ込む |

## 仕組み

- 地形は 40×24〜30×40 のブロックのグリッド。高さはノイズ（丘）とガウス関数の山・谷の足し引きで決め、水位より低いところに水を張る。木や廃墟はその後に置く
- 描画は 16³ のチャンクごとに、外に見えている面だけをまとめたメッシュ。頂点ごとに周囲のブロックの詰まり具合で陰影（AO）をつける。ブロックが壊れたらそのチャンクだけ作り直す
- 当たり判定はキャラの AABB と重なるセルだけをグリッドから引く。立方体の側面・底・天井は壊せない見えない壁
- カメラはキャラの右肩越しに、マウスで決めた向きを見る。後ろにブロックがあるとカメラを手前に寄せ、近づきすぎたらキャラを隠す。カメラとキャラを結ぶ線のまわりの地形はシェーダーで描かない
- パンチの当たり先は、カメラから照準方向へグリッドをたどる（DDA）レイキャストで決める。頭から約 3m 以内のブロックだけに届く。真下・真上を向いたときは足元・頭上のブロックを狙う
- ゴールは下のブロックを壊すと落ちてくるので、クリアできなくなることはない
- パンチが当たった瞬間にヒットストップと画面揺れを入れている
- テクスチャはすべて canvas で描いたドット絵、効果音は Web Audio で合成しているので、外部アセットは Three.js 本体だけ

## 構成

| ファイル | 内容 |
| --- | --- |
| `src/main.js` | レンダラー、後方視点のカメラと照準、ゲーム進行（タイトル / プレイ / ポーズ / クリア）・HUD |
| `src/player.js` | キャラのモデル、移動・ジャンプ・泳ぎ・よじ登り・照準へのパンチ・急降下パンチ、手足のアニメーション |
| `src/world.js` | ブロックのグリッド、チャンクのメッシュ生成、当たり判定・レイキャスト、破壊・落下・水の流れ込み、透かし表示のシェーダー |
| `src/blocks.js` | ブロックの種類（パンチ回数・破片の色・効果音）と、テクスチャアトラス |
| `src/stages.js` | ステージ定義（地形の式・水位・飾り）と地形の生成 |
| `src/markers.js` | ゴールのゲート |
| `src/effects.js` | 破片・土ぼこり・火花・水しぶき |
| `src/scenery.js` | 空のグラデーションと雲 |
| `src/audio.js` | 効果音 |
| `src/input.js` | キーボード・マウス入力、ポインターロック |

ステージを追加するときは `src/stages.js` の `STAGES` に定義を足す。`height(x, z, noise)` で地面の高さを返し、`water` で水位、`decorate(g)` で木箱や建物を置く（`g.stack()` / `g.fill()` / `g.ruin()`）。
