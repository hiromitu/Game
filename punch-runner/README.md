# Punch Runner

Three.js で作った 3D アクションゲーム。斜め上からの視点で自キャラを動かし、スタート地点から光るゴールのゲートまで進むとステージクリア。
**地面以外のオブジェクトはすべてパンチで壊せる**ので、道をふさぐ木箱や壁は壊して進んでも、よじ登って越えてもよい。ビルド不要（Three.js は CDN から importmap で読み込み）。

## 起動

Python 3 が必要。

```bash
cd Game/punch-runner
python serve.py
```

ブラウザで http://localhost:8767/ を開く。ES Modules を使うので `index.html` を直接開いても動かない。
Windows では `python -m http.server` だと `.js` が text/plain で返り読み込めないことがあるため、`serve.py` を使う。

## 操作

| 操作 | キー |
| --- | --- |
| 移動 | WASD / 矢印キー（カメラの向きが基準） |
| 走る | Shift を押しながら移動 |
| ジャンプ | Space（長押しで高く、早く離すと低く） |
| パンチ | J / K / 左クリック。走りながらだとダッシュパンチ（2 ダメージ） |
| よじ登る | 壁（オブジェクトの側面）に向かって押し続ける。空中で壁に触れると即座に掴む。縁に手が届くと上に乗り上がる |
| 壁から離れる | 登っている最中に Space（壁ジャンプ）/ 壁と反対方向へ入力 |
| カメラ | Q / E で 45° 回転、ホイールでズーム |
| その他 | R：ステージやり直し / Esc・P：ポーズ / M：音 / H：操作説明の表示切替 |

## ステージ

| # | 名前 | 内容 |
| --- | --- | --- |
| 1 | はじまりの草原 | 操作の練習。木箱の壁・石の段・レンガ壁・走りジャンプが必要な穴 |
| 2 | 石の砦 | 城壁と木箱の門、中庭、浮き足場、迷路のようなレンガ壁、石の台の上のゴール |
| 3 | 天空の回廊 | 浮き足場、5 段の大城壁、走りジャンプ必須の谷、木箱の塔の上のゴール |

穴に落ちると、最後に触れたチェックポイント（光る輪）かスタート地点から再開する。クリアタイムのベスト記録と解放済みステージは localStorage に保存する。

## 仕組み

- 当たり判定はすべて軸平行の箱（AABB）。キャラは X → Z → Y の順に動かして押し戻し、0.45m までの段差は自動で乗り越える
- オブジェクトは体力（パンチ回数）を持ち、殴るとひびが入って、0 になると破片になって消える。支えを失ったオブジェクトは落ちてくる（積んだ木箱の下を壊すと上が落ちる）
- ゴールとチェックポイントも下の支えがなくなると落ちてくるので、塔や台を壊してもクリアできなくなることはない
- カメラとキャラの間に入ったオブジェクトは半透明になる
- パンチが当たった瞬間にヒットストップと画面揺れを入れている
- テクスチャはすべて canvas で描いたドット絵、効果音は Web Audio で合成しているので、外部アセットは Three.js 本体だけ

## 構成

| ファイル | 内容 |
| --- | --- |
| `src/main.js` | レンダラー・カメラ・ゲーム進行（タイトル / プレイ / ポーズ / クリア）・HUD |
| `src/player.js` | キャラのモデル、移動・ジャンプ・よじ登り・パンチ、手足のアニメーション |
| `src/world.js` | 地面とオブジェクトの当たり判定、ダメージと破壊、支えを失ったオブジェクトの落下 |
| `src/objects.js` | オブジェクトの種類（体力・破片の色・効果音）、見た目、canvas テクスチャ |
| `src/stages.js` | ステージの配置データと、配置用のヘルパー（行・積み上げ・互い違いの壁） |
| `src/markers.js` | ゴールのゲートとチェックポイント |
| `src/effects.js` | 破片・土ぼこり・火花 |
| `src/scenery.js` | 空のグラデーションと雲 |
| `src/audio.js` | 効果音 |
| `src/input.js` | キーボード・マウス入力 |

ステージを追加するときは `src/stages.js` の `STAGES` に定義を足す。`b.floor()` で地面の島、`b.obj()` / `b.stack()` / `b.row()` / `b.wall()` でオブジェクトを置く（高さを省略するとその場所で一番高い面の上に積まれる）。
