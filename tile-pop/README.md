# タイルポップ

同じ色がつながったタイルをクリックして消していく、ブラウザ用のパズルゲーム。すべてのタイルを消せばクリア。ビルド不要・外部ライブラリなし。

## 起動

`index.html` をブラウザで直接開けば遊べる（ES Modules を使っていないのでサーバー不要）。

## ルール

- 長方形の枠の中に色の違うタイルが敷き詰められている。
- 縦か横に同じ色が隣り合っているタイルをクリックすると、つながっている同じ色のタイルがまとめて消える（2 個以上から）。
- となりに同じ色がない 1 枚だけのタイルは消せない（クリックするとタイルが揺れる）。
- 消えた所には上のタイルが落ち、空になった列は左に詰まる。
- すべて消すとクリア。消せる所がなくなりタイルが残ったら手詰まり。

## 難易度

| 難易度 | 盤面 | 色数 |
| --- | --- | --- |
| かんたん | 8 × 6 | 3 |
| ふつう | 10 × 8 | 4 |
| むずかしい | 12 × 10 | 5 |

## 得点

- 1 回に n 個消すと (n−1)² × 10 点（2 個 = 10 点、4 個 = 90 点、8 個 = 490 点）。まとめて消すほど高得点。
- クリアボーナス 1000 点。
- ヒント 1 回につき −50 点。
- 難易度ごとのベストスコアをブラウザ（localStorage）に保存する。

## 機能

- **元に戻す**：何手でも戻せる。手詰まり画面からも戻れる。
- **ヒント**：クリアにつながる一手を光らせる。
- **やり直し**：同じ盤面を最初から。
- **新しい盤面**：新しい盤面を生成。
- マウスを乗せると消える範囲と得点を表示する。
- タイルには色ごとに記号（● ▲ ■ ◆ ★）が付いていて、色の区別がつきにくくても遊べる。
- キーボード：Z 元に戻す / H ヒント / R やり直し / N 新しい盤面

## 盤面は必ずクリアできる

ランダムに色を並べるとクリア不能な盤面が多く出るため、空の盤面から「消す操作の逆」を積み重ねて作る（`logic.js` の `generate`）。

1. 逆操作は 3 種類：既存の列に縦 2〜4 個を差し込む／同じ高さの隣り合う列に横 2〜4 個を差し込む（上のタイルは押し上がる）／新しい列を差し込む。
2. 差し込んだグループが外側の同じ色と接していないことを確かめる。これで、後から順方向にそこをクリックすると、ちょうどそのグループだけが消えて差し込む前の盤面に戻る。
3. 盤面が埋まるまで繰り返し、行き詰まったら最初から作り直す。作った手順を逆にたどったものが解になる。

ヒントは、プレイヤーがこの解の途中にいればその次の一手を、外れていれば探索で見つけた一手を示す。探索は、残りが 40 枚以下なら全探索で解けるかどうかを確定させ、それより多ければ詰み（1 枚だけ残る色）を避けながらランダムに最後まで打つ試行を繰り返す。

## 構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面の骨組み |
| `style.css` | 見た目・アニメーション（ライト／ダークテーマ対応） |
| `logic.js` | 盤面の操作・生成・ソルバー（DOM に依存しないので Node からも読み込める） |
| `game.js` | 描画・入力・スコア・タイマー・ダイアログ |
